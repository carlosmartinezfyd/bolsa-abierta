# Bolsa Abierta

Prototipo abierto para consultar y comparar publicaciones de vacantes docentes de la Región de Murcia con trazabilidad de fuentes y límites de cobertura visibles.

## Demo pública

GitHub Pages sirve una versión estática del prototipo. No se actualiza automáticamente y no sustituye a las publicaciones oficiales de la CARM/RRHH Educación.

- Sin cuenta ni credenciales de Educarm.
- Sin analítica ni rastreo.
- Preferencias y favoritos guardados únicamente en el navegador.
- Los datos visibles proceden de copias históricas incorporadas al prototipo y pueden estar desactualizados.
- La fuente administrativa prevalece siempre.
